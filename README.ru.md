# Tray Alarm

Tray Alarm — настольный будильник на Electron. Приложение остаётся доступным из системного трея, поэтому будильники продолжают работать, когда главное окно скрыто или свёрнуто.

## Возможности

- Создание, изменение, включение, отключение и удаление будильников.
- Установка будильника на конкретные дату и время или быстрое напоминание через 5 секунд — 2 часа.
- Однократное, ежедневное или ежечасное расписание.
- Системное уведомление, окно будильника поверх других окон или оба варианта. В окне будильника можно отложить сигнал.
- Выбор и прослушивание встроенных звуков или отключение звука.
- Выбор часового пояса независимо от системного.
- Плавающее окно обратного отсчёта и время до ближайшего будильника в значке трея.
- Дата, день недели и относительная дата для каждого будильника.
- Сохранение будильников и настроек между запусками.

## Скачать релиз

Откройте [последний релиз](https://github.com/sigmaray/ts-electron-tray-alarm/releases/latest), скачайте ZIP-архив для своей операционной системы и распакуйте его. Доступны архивы для Windows x64, Linux x64 и macOS (выберите x64 или arm64 в соответствии с архитектурой Mac).

- **Windows:** распакуйте архив, откройте папку и запустите `Tray Alarm.exe`. Чтобы значок трея всегда отображался, откройте **Параметры → Персонализация → Панель задач → Другие значки в области уведомлений** (Windows 11) или **Выберите значки, отображаемые на панели задач** (Windows 10) и включите Tray Alarm. Если приложения ещё нет в списке, сначала запустите его. Также значок можно перетащить из скрытой области (стрелка **^**) на панель задач.
- **macOS:** распакуйте архив и откройте `Tray Alarm.app`. Если macOS заблокирует приложение, потому что оно скачано из интернета, откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите **Всё равно открыть** для Tray Alarm.
- **Linux:** распакуйте архив и запустите приложение `Tray Alarm` из распакованной папки. Если оно не запускается, откройте терминал в этой папке, разрешите запуск (`chmod +x "Tray Alarm"`), затем выполните `./Tray Alarm`.

Переносные настройки могут храниться рядом с файлами приложения, поэтому оставьте распакованную папку в месте, доступном для записи. Подробнее — в разделе [Хранение настроек](#хранение-настроек).

## Запуск приложения

Требуются Node.js версии 20 или новее и npm.

```sh
npm ci
npm run dev
```

Управляйте будильниками в окне приложения. Если скрыть или свернуть главное окно, приложение останется в системном трее. В меню трея можно снова открыть окно или завершить работу приложения. Быстрые напоминания доступны там же, в меню **New in**.

## Сборка приложения

```sh
npm run build:electron
```

В каталоге `release/` создаётся ZIP-архив для текущей платформы. Настроены сборки для Windows x64, Linux x64 и macOS x64 и arm64. При установленном [Task](https://taskfile.dev/) доступны команды `task dev`, `task build`, `task typecheck`, `task test:unit`, `task test:e2e` и `task package`.

## Проверки

```sh
npm run typecheck
npm run test:unit
npm run test:e2e
```

Набор E2E-тестов запускает Electron-приложение и может требовать графический дисплей. В CI тесты запускаются на виртуальном дисплее.

## Хранение настроек

В упакованные сборки включён маркер `portable-mode`. Если каталог с маркером доступен для записи, настройки хранятся рядом с ним в файле `settings.json`. Удалите маркер из ресурсов сборки, чтобы использовать пользовательский каталог `userData` Electron. Если переносной каталог доступен только для чтения, приложение использует `userData`. Настройки из прежних расположений в каталоге приложения переносятся при первом запуске.

Для E2E-запусков задайте `ALARM_SETTINGS_PATH`, чтобы использовать отдельный файл настроек.
