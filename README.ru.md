# Tray Alarm

Настольный будильник на Electron. Будильники продолжают работать, когда приложение свёрнуто в системный трей.

## Возможности

- Создание, изменение, включение, выключение и удаление будильников.
- Быстрая установка будильника на время от 30 секунд до 2 часов вперёд.
- Настройка повторяющихся будильников.
- Выбор часового пояса независимо от системного.
- Плавающее окно обратного отсчёта и отображение времени до ближайшего будильника в трее.
- Сохранение будильников и настроек между запусками.

## Разработка

Требования: Node.js версии 20 или новее и npm.

```sh
npm ci
npm run dev
```

Команда `dev` собирает TypeScript-код и запускает Electron-приложение. Скрипты сборки и запуска работают в Windows, macOS и Linux. Чтобы создать архив для текущей платформы, выполните:

```sh
npm run build:electron
```

Если установлен [Task](https://taskfile.dev/), доступны аналогичные команды: `task dev`, `task build`, `task typecheck`, `task test:unit`, `task test:e2e` и `task package`.

## Тесты

```sh
npm run typecheck
npm run test:unit
npm run test:e2e
```

E2E-набор запускает настоящее Electron-приложение и может требовать графический дисплей. В CI тесты запускаются на виртуальном дисплее.

## Хранение настроек

Все упакованные сборки содержат маркер `portable-mode` и хранят настройки рядом с ресурсами приложения, если эта папка доступна для записи. Удалите маркер из ресурсов сборки, чтобы использовать пользовательскую папку `userData`, определённую Electron. При первом запуске настройки из прежних папок приложения переносятся автоматически. Если переносная папка доступна только для чтения, приложение использует `userData`.

Для E2E-запусков переменная `ALARM_SETTINGS_PATH` позволяет указать отдельный файл настроек.
